# هما (Homa)

نرم‌افزار دسکتاپ مدیریت آموزشگاه روی ویندوز: مشتریان، جلسات چندکلاسه، حضور RFID، صندوق و پشتیبان محلی. همهٔ داده‌ها روی همین رایانه می‌ماند.

محصول نهایی نصب‌کنندهٔ NSIS با نام **هما** است (`Homa-Setup-1.0.0.exe`).

## امکانات

- داشبورد روز، تقویم هفتگی (شنبه تا جمعه)، کیوسک حضور
- مشتریان با دوره، عکس، ورود از Excel و کارت RFID
- آموزشگاه: کلاس، مربی، بسته، گروه نام‌دار، تعطیلات
- حضور RFID یا دستی؛ وضعیت جلسه: رزرو / حاضر / غایب / لغو / جبرانی
- صندوق، بدهی، گزارش بازه، یادآوری واتساپ و پیامک
- پشتیبان دستی و پشتیبان روزانهٔ خودکار (پایگاه + عکس)

## پیش‌نیازها

- Node.js ۱۸ یا بالاتر
- ویندوز (هدف اصلی بسته‌بندی)
- خواننده RFID سریال (اختیاری)

## نصب و اجرا

```bash
npm install
npm run dev
```

`npm install` ماژول‌های native (`better-sqlite3` و `serialport`) را برای Electron بازسازی می‌کند.

حالت توسعه دو فرآیند را با هم اجرا می‌کند:

1. Vite روی `http://127.0.0.1:5173`
2. Electron بعد از آماده شدن Vite

## ساخت نسخه نهایی

```bash
npm run build    # کامپایل renderer و main process
npm run dist     # آیکن + بیلد + ساخت نصب‌کننده در release/
```

اگر `build/icon.png` نبود، `npm run dist` خودکار آن را می‌سازد؛ یا دستی: `npm run icon`.

خروجی: `release/Homa-Setup-1.0.0.exe`

اگر پایگاه داده خراب باشد برنامه پیام می‌دهد و بسته می‌شود. اجرای دوم همان برنامه پنجرهٔ قبلی را جلو می‌آورد.

## معماری

- **Main:** `electron/` — پنجره، IPC، SQLite، RFID، عکس، پشتیبان
- **Preload:** `electron/preload.ts` — فقط کانال‌های مجاز
- **Renderer:** `renderer/` — React + HashRouter (مناسب `loadFile` در نسخه نصب‌شده)
- **Shared:** `shared/` — نوع‌ها و منطق مشترک تست‌پذیر

دیتابیس و عکس‌ها در userData ویندوز ذخیره می‌شوند، نه کنار سورس:

`%APPDATA%/هما/database.sqlite`

اختیاری: فایل `%APPDATA%/هما/.env` برای `RFID_PORT` بدون بازسازی برنامه.

## RFID

1. پورت را از **تنظیمات** انتخاب کنید، یا `RFID_PORT` را در `.env` بگذارید.
2. خط ۱۰ کاراکتر هگز یعنی UID کارت.
3. اگر صفحهٔ ساخت/ویرایش مشتری باز باشد UID روی فرم می‌نشیند و جلسه مصرف نمی‌شود.

نمونه `.env`:

```
RFID_PORT=COM3
```
